Grand Line Study — نسخهٔ وب قابل نصب (PWA)

این پوشه شامل نسخهٔ اولیهٔ برنامه است:
- ثبت فعالیت، تاریخ، درس، مبحث، ساعت و مدت
- ثبت تعداد تست و پاسخ درست، تمرکز و تسلط
- ذخیرهٔ محلی در مرورگر گوشی
- نمودار زمان مطالعه بر اساس درس
- خروجی CSV و چاپ/ذخیرهٔ گزارش به PDF
- پوستهٔ تیره با الهام از ماجراجویی‌های دریایی

نکتهٔ مهم:
فایل‌ها را که فقط در حافظهٔ گوشی باز کنی، نصب PWA و حالت آفلاین کامل فعال نمی‌شود.
برای نصب از Chrome، فایل‌ها باید روی یک آدرس HTTPS منتشر شوند. راه ساده با گوشی:
1) وارد GitHub شو و یک repository جدید بساز.
2) فایل‌های همین ZIP را در repository بارگذاری کن (Add file > Upload files).
3) در Settings > Pages، گزینهٔ Deploy from a branch را انتخاب کن، Branch = main و Folder = /(root).
4) بعد از انتشار، لینک سایت را در Chrome باز کن و از منوی سه‌نقطه Add to Home screen / Install app را بزن.

داده‌ها فعلاً در localStorage همان مرورگر و همان دستگاه ذخیره می‌شوند؛ پاک‌کردن داده‌های سایت یا عوض‌کردن مرورگر می‌تواند آن‌ها را حذف کند. برای نگهداری مطمئن، CSV خروجی بگیر.
نسخهٔ اولیه است؛ قبل از ثبت داده‌های مهم، چند ورودی آزمایشی ثبت و خروجی بگیر.
